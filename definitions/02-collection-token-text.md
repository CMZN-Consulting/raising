# `[]`, token, text

Depends on: nothing. Lean: `Raising.Collection`, `Raising.Token`, `Raising.Text`, in `Raising/Object.lean` and `Raising/Language.lean`.

A collection, written `[]`, is an ordered list of things of one type: Lean's list under the framework's name, with Lean's `[a, b, c]` notation.

A token is the unit of text, named by a number. A text is a collection of tokens.
