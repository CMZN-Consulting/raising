# Definitions

These are the definitions of raising in the English register. They are read in order: no definition uses a word that a later definition defines.

## How a definition is written

- In basic English, in the fewest words that satisfy, with the fewest free choices. A free choice is a constant or a parameter that no proof needs.
- Naming what it depends on.
- Stating the register of every claim it makes: proved, measured, or recorded.

## How a definition changes

See `19-refinement.md`. The changelog keeps every legacy text and names every change as a refinement or a revision.

## Words this repository does not use

- "undefinable". A meta-variable is filled, deferred, or open.
- "proved", of anything the Lean kernel did not check.
- Any sentence that says how an individual will act.
