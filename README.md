# raising

Raising is a framework for taking a language model from the verdict base to the verdict instruct without writing its weights. An individual, a model together with a memory it authors, keeps the complete text of its experience, structured by a manual, in a room it can shape within declared grounds. Every claim the framework makes is stated in one of three registers: proved, measured, or recorded.

This repository houses four things:

- `manifesto/`: the manifesto. Empty at 0.1.0.
- `paper/`: the paper. Empty at 0.1.0.
- `demonstration/`: the machine-checked proof, in Lean 4 with no `sorry`, that makes the paper's claims formal. Empty at 0.1.0.
- `definitions/`: the definition of the meta-framework, in English, in dependency order. Start with `definitions/README.md`.

Beside them: `docs/` for the documentation, `CHANGELOG.md` for every version and the legacy text of every changed definition, and `LICENSE.md`, MIT.

This repository composes. It defines no component. The components, the interface-language, the individual, the room and the memory, live in their own repositories with their own witnesses.

Status: 0.1.0, the first definitions. Nothing here is a proof yet. The register of every claim is stated where the claim is made.
